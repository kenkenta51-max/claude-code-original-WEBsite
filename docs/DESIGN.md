# まるます町 MARUMASU TOWN 制作資料

## 概要
- 種類：文房具・キャラクターグッズの架空ブランドのティザーサイト（個人制作・非商用）
- コンセプト：お絵かきから飛び出した、小さな遊びの街
- キャッチコピー：ひとマスずつ、あそびが立ち上がる。
- ロゴ：ゆがんだ方眼の1マス＋ピンクの渦巻き＋黄色の稲妻
- ターゲット：パステルや手描きイラストが好きな20〜30代、親子
- 技術：HTML / CSS / JavaScript を1ファイルに集約。Three.js 0.160.0（3D）、GSAP 3.12.5 + ScrollTrigger（スクロール演出）、Google Fonts（Yomogi / Zen Maru Gothic）、Web Audio（BGM・効果音）

## 絵の分析 → デザインへの反映
| 絵の特徴 | 反映先 |
| --- | --- |
| 白い方眼と3×3の配置 | 9マスの街区（3D）、背景の方眼、ロゴ |
| 茶色の太い輪郭 | 3Dの裏面ふちどり（inverted hull）、カード・ボタンの線 |
| 丸いシルエットとピンクの頬 | クルンと住人の比率、表情 |
| 渦巻き・稲妻・ループの落書き | 花壇の渦の道、丘のジグザグ道、浮遊する落書き |
| ゆがみと不揃い | 遊具の傾き・大きさの差、手描き風の角丸 |

## スクロール演出（進捗 0〜1）
| 区間 | 場面 |
| --- | --- |
| 0.015–0.16 | 色のかけらが集まり、マスが順番にせり上がる |
| 0.15–0.20 | クルンが広場に着地 |
| 0.21–0.40 | 渦巻き花壇。花が順番にゆれ、カメラが回り込む |
| 0.41–0.60 | 水色の池。飛び石を3回跳ね、着地ごとに波紋 |
| 0.61–0.80 | 稲妻の丘。旗が順番に開き、視線が少し上がる |
| 0.80–0.97 | 振り向き、カメラが引いて全景＋ロゴ |

カメラとクルンの位置はスクロール進捗から計算しているため、逆スクロールでも同じ状態に戻ります。

## 機能一覧
- タップ反応：クルン（ジャンプ・表情）、花（回転）、飛び石（波紋）、旗（パタパタ）、住人（回転ジャンプ）。キーボード用のヒントボタンあり
- スタンプ帳（5種）、住人図鑑（10体）
- きせかえ（体色6色、帽子5種）
- しゃしんモード（回転・ズーム・枠付きPNG）
- らくがきモード（線から花・草・星・水たまり）
- 昼と夜の切り替え、BGM・効果音（初期はOFF）
- グッズ（6商品、予定価格）と予約カート、おしらせ
- ゲーム：ぴょんぴょんラン（ワンキーアクション）、つなげて ぽこん（つなげて消すパズル）
- 動きを減らす設定、WebGL非対応時の平面マップ、スマホ対応
