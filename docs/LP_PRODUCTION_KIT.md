# AIと作るLP制作キット（構成・指示文・仕様書）

AIで出したLPの初稿を「素人っぽい」状態で終わらせないための制作手順です。
仕上げの5つの指示（余白・文字の大きさ・申し込みボタン・写真・見出しの長さ）を、構成・原稿・仕様書の段階から組み込んでいます。

- 【 】の部分は案件ごとに書き換えてください。
- 「推奨値」は迷ったときの目安です。案件に合わせて変えてかまいません。

---

## 0. 制作の流れ

| 手順 | やること | 使う指示文 |
| --- | --- | --- |
| 1 | 案件情報（ヒアリングシート）を埋める | — |
| 2 | AIに構成を作ってもらう | 指示文A |
| 3 | AIに原稿を書いてもらう | 指示文B |
| 4 | AIにデザインの初稿を作ってもらう | 指示文C |
| 5 | 仕上げの5つの指示を **1回に1つずつ** 打つ | 指示文D-1〜D-5 |
| 6 | チェックリストで確認してからお客様に見せる | 4章 |

> 指示は1回に1つずつ。まとめて言うと、どれかが抜けやすくなります。

## 1. ヒアリングシート（案件情報）

指示文A〜Cの先頭にそのまま貼って使います。

```
【案件情報】
・サービス／商品名：【　】
・提供者（会社名・屋号・氏名）：【　】
・一言でいうと何か：【　】
・ターゲット（年代・立場・状況）：【　】
・ターゲットの悩み（3つ）：【　】【　】【　】
・解決できること／得られる変化：【　】
・選ばれる理由・強み（3つ）：【　】【　】【　】
・実績・お客様の声：【　】
・料金：【　】
・申し込みの流れ：【　】
・よくある質問：【　】
・ゴール（LPで取ってほしい行動）：【例：無料相談の申し込み】
・申し込みボタンの文言：【例：無料で相談する】
・ブランドの雰囲気：【例：やさしい／信頼感／高級感】
・メインで使う写真：【例：施術中の写真、本人の写真】
```

## 2. サイト構成（LPの基本構成）

スマホで上から順に読まれる前提の、1ページ完結型の構成です。

| No. | セクション | 役割 | 主な要素 | 見出し例（15文字以内） | ボタン |
| --- | --- | --- | --- | --- | --- |
| 1 | ファーストビュー | 3秒で「自分向けだ」と思ってもらう | キャッチコピー、サブコピー、メイン写真（横幅いっぱい） | 【例：朝5分で肌が変わる】 | ◯ |
| 2 | 悩み・共感 | 「わかってくれている」と感じてもらう | 悩み3つ（チェックリスト形式） | 【例：こんなお悩みありませんか】 | — |
| 3 | 解決策 | 悩みの答えとしてサービスを示す | サービス概要、得られる変化 | 【例：その悩み、解決できます】 | — |
| 4 | 選ばれる理由 | 他との違いを伝える | 強み3つ（小見出し＋説明文） | 【例：選ばれる3つの理由】 | — |
| 5 | 実績・お客様の声 | 信頼してもらう | 実績の数字、お客様の声2〜3件 | 【例：お客様の声】 | ◯ |
| 6 | 料金 | 判断材料を出す | 料金表、含まれる内容 | 【例：料金プラン】 | — |
| 7 | ご利用の流れ | 申し込み後の不安をなくす | 3〜4ステップ | 【例：お申し込みの流れ】 | — |
| 8 | よくある質問 | 最後の迷いを解消する | Q&A 4〜6件 | 【例：よくあるご質問】 | — |
| 9 | 最後の申し込み | 行動してもらう | 一言の後押し、申し込みボタン | 【例：まずは無料相談から】 | ◯ |
| 10 | フッター | 運営者情報 | 運営者名、リンク、コピーライト | — | — |

### 構成に組み込む5つのルール
- **余白**：セクションの上下の余白は推奨値（3章）を使う。詰めない。
- **文字の大きさ**：どのセクションも「見出し・小見出し・本文」の3段階だけで組む。
- **申し込みボタン**：No.1・5・9に置く。3つとも同じ色・同じ文言にする。
- **写真**：ファーストビューに1枚、横幅いっぱいで大きく使う。小さい写真を並べるだけのセクションは作らない。
- **見出しの長さ**：すべてのセクション見出しを15文字以内にする。

## 3. 仕様書

### 3-1. 基本情報

| 項目 | 内容 |
| --- | --- |
| 案件名 | 【　】のLP制作 |
| 目的・ゴール | 【例：無料相談の申し込み数を増やす】 |
| ターゲット | 【　】 |
| ページ構成 | 1ページ完結のLP（2章の構成） |
| 対応端末 | スマホ優先。PC・タブレットにも対応 |
| 対応ブラウザ | Chrome／Safari／Edge／Firefox の最新版、iOS Safari、Android Chrome |
| 公開予定日 | 【　】 |

### 3-2. デザインルール（仕上げの5つの指示）

#### ① 余白：セクションの上下の余白はAIの初稿の1.5倍
AIの初稿は詰まりがちなので、最初から広めにとります。

| 項目 | PC | スマホ |
| --- | --- | --- |
| セクションの上下の余白（推奨値） | 120px | 72px |
| 参考：よくある初稿の余白 | 80px | 48px |
| 左右の余白 | 中央寄せ・最大幅 1080px | 20px |
| 見出しと本文の間 | 32px | 24px |

#### ② 文字の大きさ：見出し・小見出し・本文の3段階
この3段階以外のサイズは使いません（注釈・コピーライトだけ例外で小さくしてよい）。

| 段階 | 用途 | PC | スマホ | 太さ | 行間 |
| --- | --- | --- | --- | --- | --- |
| 見出し | 各セクションのタイトル、キャッチコピー | 40px | 26px | 太字 | 1.4 |
| 小見出し | 強みの項目名、Q&Aの質問など | 24px | 19px | 太字 | 1.5 |
| 本文 | 説明文 | 16px | 16px | 標準 | 1.8 |

#### ③ 申し込みボタン：色も文言も1種類
| 項目 | 内容 |
| --- | --- |
| 文言 | 【例：無料で相談する】（全ボタンで同じ） |
| 色 | 【例：#E86A4A】（全ボタンで同じ。ほかの要素にはこの色を使わない） |
| 置き場所 | ファーストビュー／お客様の声の後／ページ最後 |
| サイズ | スマホは横幅いっぱい・高さ56px以上 |
| リンク先 | 【例：申し込みフォームのURL】 |

#### ④ 写真：1枚を横幅いっぱいで大きく
| 項目 | 内容 |
| --- | --- |
| メイン写真 | ファーストビューに1枚、画面の横幅いっぱい |
| 写真の内容 | 【　】 |
| 禁止 | 小さい写真をパラパラ並べるだけのレイアウト |
| 書き出し | 横幅 2000px 程度、WebP（またはJPEG）、1枚300KB以下が目安 |

#### ⑤ 見出しの長さ：15文字以内
- セクション見出し・キャッチコピーは15文字以内にする。
- 理由：長い見出しはスマホで3行になり、読みにくいため。
- 補足：スマホでは見出し（26px）が1行に約12〜13文字入るので、15文字以内なら2行に収まります。

## 4. お客様に見せる前のチェックリスト

- [ ] セクションの上下の余白が推奨値になっている（PC 120px／スマホ 72px）
- [ ] 文字の大きさが「見出し・小見出し・本文」の3段階だけになっている
- [ ] 申し込みボタンの色と文言がすべて同じ
- [ ] ファーストビューの写真が1枚、横幅いっぱいで大きく使われている
- [ ] すべての見出しが15文字以内で、スマホで3行になっていない
- [ ] スマホの実機で表示を確認した
- [ ] 申し込みボタンのリンク先が正しい
- [ ] 誤字脱字、料金・日付・連絡先に間違いがない

## 5. 指示文（AIへのプロンプト）

### 指示文A：構成を作る

```
あなたはLP制作のプロのWebディレクターです。
以下の案件情報をもとに、LPの構成案を作ってください。

【案件情報】
（1章のヒアリングシートを貼る）

【条件】
・スマホで上から読まれる、1ページ完結のLPにする
・セクションは次の順番を基本にする：
　ファーストビュー／悩み・共感／解決策／選ばれる理由／実績・お客様の声／料金／ご利用の流れ／よくある質問／最後の申し込み／フッター
・各セクションについて「役割」「入れる要素」「見出し案」を表で出す
・見出し案はすべて15文字以内にする
・申し込みボタンは、ファーストビュー・お客様の声の後・ページ最後の3か所に置く
・ターゲットに合わないセクションがあれば、理由をつけて削除や追加を提案する
```

### 指示文B：原稿を書く

```
あなたはLPのコピーライターです。
以下の案件情報と構成をもとに、LPの原稿を書いてください。

【案件情報】
（1章のヒアリングシートを貼る）

【構成】
（指示文Aで決まった構成を貼る）

【書き方のルール】
・各セクションを「見出し」「小見出し」「本文」の3段階で書く（それ以外の階層は作らない）
・見出しは15文字以内にする（スマホで3行にならないように）
・キャッチコピーは15文字以内の案を3つ出す
・申し込みボタンの文言は「【ボタンの文言】」の1種類だけを使う
・本文は1段落3行程度までにして、詰め込みすぎない
・ターゲットが普段使う言葉で、専門用語はかみくだいて書く
・事実がわからない部分（実績の数字、お客様の声など）は作らずに【要確認】と書く
・最後に、各見出しの文字数一覧をつける
```

### 指示文C：デザインの初稿を作る

```
以下の原稿と仕様で、LPを1ページのHTML／CSSで作ってください。

【原稿】
（指示文Bで決まった原稿を貼る）

【デザインの仕様】
・スマホ優先のレスポンシブ（最大幅1080px、スマホの左右余白20px）
・セクションの上下の余白：PC 120px／スマホ 72px
・文字の大きさは3段階のみ
　見出し：PC 40px／スマホ 26px（太字）
　小見出し：PC 24px／スマホ 19px（太字）
　本文：16px（行間1.8）
・申し込みボタン：色は【ボタンの色】、文言は「【ボタンの文言】」で統一。
　ファーストビュー・お客様の声の後・ページ最後の3か所。スマホは横幅いっぱい・高さ56px以上
・写真：ファーストビューに1枚、横幅いっぱいで大きく使う（写真は【写真の内容】。仮の画像でよい）
・雰囲気：【ブランドの雰囲気】、メインカラー：【メインカラー】、フォント：【フォント】
```

### 指示文D：仕上げの5つの指示（1回に1つずつ）

初稿ができたら、次の5つを **1つずつ** 打ちます。1つ打つたびに結果を見て、直っていることを確かめてから次に進みます。

**D-1 余白**
```
セクションの上下の余白を1.5倍にして
```

**D-2 文字の大きさ**
```
見出し・小見出し・本文の3段階を基本にして
```

**D-3 申し込みボタン**
```
申し込みボタンは色も文言も1種類にそろえて
```

**D-4 写真**
```
写真を1枚、横幅いっぱい大きく使って
```

**D-5 見出しの長さ**
```
【対象の見出し】の見出しを15文字以内にして
```
（例：「ファーストビューの見出しを15文字以内にして」のように、どの見出しかを指定する）

> 指示文Cで最初から仕様を伝えていても、AIの初稿では崩れていることがあります。D-1〜D-5で必ず仕上げてから、4章のチェックリストで確認してください。
